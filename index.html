webserv

A lightweight HTTP/1.1 server written from scratch. A single poll() loop multiplexes every socket with non-blocking I/O, so a slow client never holds up the rest. Behaviour comes from an nginx-style config file.

  • Request parsing, response building and error handling to the HTTP/1.1 RFCs
  • GET, POST and DELETE, with allowed methods set per route
  • Virtual servers on several ports; Python and Bash CGI
  • File uploads, autoindex listings, redirects and body size limits
  • Modular design: server, routing and configuration parsing kept separate
